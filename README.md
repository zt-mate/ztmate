ztmate
======

What is it?
-----------

`ztmate` is a Zig-refactored fork of `tmate` / `tmux` providing instant terminal pairing and sharing.

Build & Test
------------

```bash
zig build
zig build test --summary all
```

The built binary is located at `./zig-out/bin/ztmate`.
